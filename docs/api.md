# API Reference

Base URL when running locally: `http://127.0.0.1:8000`

Interactive Swagger UI is auto-generated by FastAPI at `/docs` (and ReDoc at `/redoc`) —
this file is a quick reference, not a replacement for it.

## Health

### `GET /health`
Liveness check.
```json
{"status": "ok", "service": "payback-ai"}
```

## Transactions

### `GET /transactions`
List failed payments.

| Query param | Type | Default | Notes |
|---|---|---|---|
| `failure_category` | string | none | exact match filter |
| `merchant_id` | string | none | exact match filter |
| `limit` | int | 50 | 1–500 |
| `offset` | int | 0 | ≥ 0 |

```bash
curl "http://127.0.0.1:8000/transactions?failure_category=suspected_risk&limit=5"
```

### `GET /transactions/{transaction_id}`
Full detail: payment fields, latest classification + recovery probability, latest decision
(action, reason, safety_checks, requires_human_review), and both baseline and PayBack AI
simulated outcome status (if the corresponding pipeline stage has run).

Returns `404` if the transaction doesn't exist.

## Decisions

### `GET /decisions/{transaction_id}`
Computes the decision **live** (does not persist). Useful for previewing what the system
would decide right now, e.g. after a data or model change.

### `POST /decisions/{transaction_id}/run`
Computes the decision live and **persists** it to `recovery_decisions` (replacing any prior
row for that transaction), logging the recomputation to `audit_logs`.

Both return:
```json
{
  "transaction_id": "TXN000123",
  "action": "human_escalation",
  "recovery_probability": 0.42,
  "confidence": 0.95,
  "reason": "...",
  "safety_checks": [{"rule": "...", "triggered": true, "detail": "..."}],
  "requires_human_review": true
}
```
Both return `404` if the transaction doesn't exist.

## Metrics

### `GET /metrics/baseline`
Fixed-retry baseline metrics (requires `python -m core.baseline` to have run).

### `GET /metrics/payback-ai`
PayBack AI metrics (requires `python -m core.simulator` to have run).

### `GET /metrics/comparison`
```json
{"baseline": {...}, "payback_ai": {...}}
```

### `GET /metrics/recovery-model`
Reads `models/recovery_model_metrics.json` (requires `python -m core.recovery_model` to
have run). Returns a `detail` message instead of metrics if the file doesn't exist yet.

## Error shape

All errors follow FastAPI's standard shape:
```json
{"detail": "Transaction 'TXN_NOPE' not found"}
```
`404` for missing resources, `422` for invalid query parameters (e.g. `limit=0` or
`limit=100000`, both outside the enforced 1–500 range).
